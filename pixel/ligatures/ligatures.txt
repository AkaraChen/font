# AKR Pixel SC — hand-drawn programming ligatures
#
# Every glyph below is drawn by hand on the same pixel grid Fusion Pixel 12px
# uses. Nothing here is traced, scaled or rasterized from another font.
#
# GRID
#   12 rows tall. Row 0 is the top. 1 row = 1 pixel = 100 font units.
#   ascent = 1000, descent = -200, so:
#     row 0  -> y 1000..900      row 6  -> y  400..300
#     row 2  -> y  800..700  (cap top)
#     row 9  -> y  100..0    (baseline is the BOTTOM of row 9)
#     row 11 -> y -100..-200
#
#   6 columns per character cell (1 cell = 600 units = one half-width column).
#   An N-character ligature is 6N columns wide and advances N * 600.
#   Fusion's own glyphs ink columns 0..4 of each cell and leave column 5 as the
#   inter-character gap, so ligature ink normally stops at column 6N-2.
#
# REFERENCE — the base font's own strokes, so hand-drawn shapes stay consistent:
#   '='  bars on rows 5 and 7, cols 0..4      '-'  bar on row 6
#   '<'  apex row 6 col 1, arms rows 3..9     '>'  apex row 6 col 4
#   '!'  stem col 2 rows 2..7, dot row 9      '|'  col 2, rows 1..10
#   '/'  rows 1,2->col4  3,4->col3  5,6->col2  7,8->col1  9,10->col0
#   '*'  row 4 col 2 / row 5 cols 0,2,4 / row 6 cols 1,2,3 / row 7 cols 0,2,4 / row 8 col 2
#   ':'  dots rows 4 and 9, col 2             '.'  dot row 9, col 2
#   '+'  stem col 2 rows 4..8, bar row 6 cols 0..4
#
# FORMAT
#   '@ <sequence>' starts a glyph, followed by exactly 12 rows of '#' / '.'.
#   Row width must be exactly 6 * len(sequence). The builder hard-fails otherwise.
#   Lines starting with '#' at column 0 that are not 12-row art are comments.
#
# ---------------------------------------------------------------------------
# 2-cell ligatures (12 columns)
# ---------------------------------------------------------------------------
